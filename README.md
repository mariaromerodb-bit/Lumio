# Lumio# 🎬 Lumio ✨
Una aplicación web interactiva para descubrir películas y series, realizar búsquedas y crear una biblioteca personalizada con tus títulos favoritos.

---

## 🚀 Requisitos Funcionales

🔎 **DEBE** permitir buscar películas y series por nombre.

🎞️ **DEBE** mostrar información detallada de cada título (imagen, sinopsis, valoración, fecha, etc.).

📚 **DEBE** permitir añadir películas y series a una biblioteca personal.

❤️ **DEBE** permitir eliminar títulos de la biblioteca.

🔄 **DEBE** actualizar automáticamente la biblioteca cuando se añadan o eliminen elementos.

📱 **DEBE** ofrecer una interfaz responsive para una correcta visualización en cualquier dispositivo.

---

## 💻 Tecnologías Utilizadas

🌐 HTML5

🎨 CSS3

⚡  React

🎬 API de películas y series (TMDB)
